# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- **GitHub:** use [Report a vulnerability](https://github.com/ChronicStone/typed-xlsx/security/advisories/new) on the Security tab. This opens a private advisory that only the maintainer can see.
- **Email:** cthao.pro@gmail.com, with "typed-xlsx security" in the subject.

Include the typed-xlsx version, a minimal schema or input that shows the problem, and what an attacker could do with it. Cell values, formulas and hyperlinks built from untrusted data are the most likely places for issues.

You'll get a reply within 3 working days. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Only the latest 5.x release gets security fixes.
