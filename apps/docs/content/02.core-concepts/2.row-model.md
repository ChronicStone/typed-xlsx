In report mode, one object from your `rows` array can produce several worksheet rows. Every formula API in typed-xlsx is built around that split:

- a **logical row** is one object from `rows`
- a **physical row** is one row of the worksheet

`refs.column()` and `column.cells()` work on physical rows. `row.series()` and `column.rows()` work on logical rows. The rest of this page shows what each one writes into the file.

## One input row, several worksheet rows

When an accessor returns an array, the logical row expands into one physical row per item. Columns with a single value are merged across the expanded rows.

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{ customer: string; monthlyAmounts: number[] }>()
  .column("customer", { header: "Customer", accessor: "customer" })
  .column("monthlyAmount", {
    header: "Monthly amount",
    accessor: (row) => row.monthlyAmounts,
  })
  .build();
```

Sub-row expansion is report-mode only. In [excel-table mode](/excel-tables/table-mode) every logical row stays one physical row.

## `refs.column()` points at the current physical row

`refs.column(id)` references the cell of that column on the same worksheet row as the formula. On an expanded row, each physical row gets its own formula.

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{ qty: number[]; unitPrice: number[] }>()
  .column("qty", { header: "Qty", accessor: (row) => row.qty })
  .column("unitPrice", { header: "Unit price", accessor: (row) => row.unitPrice })
  .column("lineTotal", {
    header: "Line total",
    formula: ({ refs }) => refs.column("qty").mul(refs.column("unitPrice")),
    expansion: "expand",
  })
  .build();
```

::sheet-figure
---
columns: [Qty, Unit price, Line total]
rows: [[2, 50, "=(A2*B2)"], [3, 40, "=(A3*B3)"], [1, 80, "=(A4*B4)"]]
marks:
  - { range: C2:C4, label: "one formula per physical row, each pointing at its own row" }
---
::

Use it for line totals, per-line margins, and any comparison that should follow each worksheet row.

## `row.series()` points at the whole logical row

`row.series(id)` references every physical cell the current logical row produced for that column. It is the tool for one result per source record.

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{ customer: string; monthlyAmounts: number[] }>()
  .column("customer", { header: "Customer", accessor: "customer" })
  .column("monthlyAmount", {
    header: "Monthly amount",
    accessor: (row) => row.monthlyAmounts,
  })
  .column("rowAverage", {
    header: "Average",
    formula: ({ row, fx }) => fx.round(row.series("monthlyAmount").average(), 2),
    expansion: "single",
  })
  .build();
```

::sheet-figure
---
columns: [Customer, Monthly amount, Average]
rows: [[Acme, 100, "=ROUND(AVERAGE(B2:B4),2)"], [null, 120, null], [null, 140, null]]
merges: [A2:A4, C2:C4]
marks:
  - { range: B2:B4, label: "row.series(\"monthlyAmount\") covers the logical row's span" }
  - { range: C2:C4, label: "one result for the logical row, merged (expansion: \"single\")" }
---
::

`row.series()` exposes `.sum()`, `.average()`, `.min()` and `.max()`.

## Both compose with the same operators

`refs.column()` and `row.series()` return the same kind of formula operand, so `.mul()`, `.sub()`, `fx.round()` and the rest work on both. What changes is the cells they point at.

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{
  qty: number[];
  unitPrice: number[];
  discountPct: number;
}>()
  .column("qty", { header: "Qty", accessor: (row) => row.qty })
  .column("unitPrice", { header: "Unit price", accessor: (row) => row.unitPrice })
  .column("discountPct", { header: "Discount", accessor: "discountPct" })
  .column("lineNet", {
    header: "Line net",
    formula: ({ refs, fx }) =>
      refs
        .column("qty")
        .mul(refs.column("unitPrice"))
        .mul(fx.literal(1).sub(refs.column("discountPct"))),
    expansion: "expand",
  })
  .column("orderAverage", {
    header: "Order average",
    formula: ({ row, fx }) => fx.round(row.series("lineNet").average(), 2),
    expansion: "single",
  })
  .build();
```

## `expansion` decides how many cells get the result

The formula decides what to compute. `expansion` decides where it is written on an expanded row:

| Value      | Writes                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| `"single"` | once, on the first physical row, merged across the rest                                                               |
| `"expand"` | on every physical row                                                                                                 |
| `"auto"`   | the default: `single` when the formula reads a whole logical row (`row.series`), `expand` when it reads `refs.column` |

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{ amounts: number[] }>()
  .column("amount", { header: "Amount", accessor: (row) => row.amounts })
  .column("averageOnce", {
    header: "Average once",
    formula: ({ row }) => row.series("amount").average(),
    expansion: "single",
  })
  .column("averageRepeated", {
    header: "Average repeated",
    formula: ({ row }) => row.series("amount").average(),
    expansion: "expand",
  })
  .build();
```

::sheet-figure
---
columns: [Amount, Average once, Average repeated]
rows: [[100, "=AVERAGE(A2:A4)", "=AVERAGE(A2:A4)"], [120, null, "=AVERAGE(A2:A4)"], [140, null, "=AVERAGE(A2:A4)"]]
merges: [B2:B4]
marks:
  - { range: B2:B4, label: "single" }
  - { range: C2:C4, label: "expand" }
---
::

## Summaries make the same choice

Summary formulas below the table pick between physical cells and logical rows too:

- `column.cells()` aggregates every worksheet cell in the column
- `column.rows()` resolves one value per logical row first, then aggregates those

With two customers where Acme expanded into three rows, the two averages differ:

```ts twoslash
import { createExcelSchema } from "typed-xlsx";

const schema = createExcelSchema<{ customer: string; monthlyAmounts: number[] }>()
  .column("customer", {
    header: "Customer",
    accessor: "customer",
    summary: (summary) => [summary.label("Cells avg"), summary.label("Rows avg")],
  })
  .column("monthlyAmount", {
    header: "Monthly amount",
    accessor: (row) => row.monthlyAmounts,
    summary: (summary) => [
      summary.formula(({ column }) => column.cells().average()),
      summary.formula(({ column }) =>
        column.rows().average((row) => row.cells().average()),
      ),
    ],
  })
  .build();
```

::sheet-figure
---

rows: [[Acme, 100], [null, 120], [null, 140], [Globex, 300]]
summaries: [["Cells avg", "=AVERAGE(B2:B5)"], ["Rows avg", "=AVERAGE(AVERAGE(B2:B4),AVERAGE(B5:B5))"]]
merges: [A2:A4]
widths: [110, 330]
marks:

## Which one to use

| You want                                                      | Use                   |
| ------------------------------------------------------------- | --------------------- |
| a value per worksheet row (line totals, per-line checks)      | `refs.column()`       |
| one value per source record (order totals, customer averages) | `row.series()`        |
| that value written once and merged                            | `expansion: "single"` |
| that value repeated on every expanded row                     | `expansion: "expand"` |
| a summary over every worksheet cell                           | `column.cells()`      |
| a summary where each source record counts once                | `column.rows()`       |
