`.sheet(name, options)` takes the same options in the buffered and streaming builders.

| Option           | Default | Purpose                                                       |
| ---------------- | ------- | ------------------------------------------------------------- |
| `freezePane`     |         | `{ rows, columns }` that stay visible while scrolling         |
| `tablesPerRow`   | `1`     | how many tables sit side by side before wrapping to a new row |
| `tableColumnGap` | `1`     | empty columns between side-by-side tables                     |
| `tableRowGap`    | `1`     | empty rows between stacked tables                             |
| `rightToLeft`    | `false` | mirror the sheet for right-to-left languages                  |
| `protection`     |         | `true` or permissions, see [Protection](/workbook/protection) |

## Freeze panes

Freeze the rows a reader needs while scrolling, usually the title and header rows, and the identifying columns on wide reports.

```ts twoslash
import { createExcelSchema, createWorkbook } from "typed-xlsx";

type Account = { account: string; jan: number; feb: number; mar: number };

const schema = createExcelSchema<Account>()
  .column("account", { header: "Account", accessor: "account" })
  .column("jan", { header: "Jan", accessor: "jan" })
  .column("feb", { header: "Feb", accessor: "feb" })
  .column("mar", { header: "Mar", accessor: "mar" })
  .build();

createWorkbook()
  .sheet("Revenue", { freezePane: { rows: 2, columns: 1 } })
  .table("revenue", { title: "Monthly revenue", schema, rows: [] });
```

::sheet-figure
---
title: Monthly revenue
columns: [Account, Jan, Feb, Mar]
rows: [[Acme, 4200, 4400, 4900], [Globex, 8750, 8100, 9300], [Initech, 1200, 1300, 1250]]
freeze: { rows: 2, cols: 1 }
widths: [110, 80, 80, 80]
marks:
  - { range: A1:D2, label: "frozen rows: the title and the header stay on screen" }
  - { range: A3:A5, label: "frozen column: the account name stays visible when scrolling right" }
---
::

`freezePane` counts worksheet rows and columns, so with a table title the header is row 2.

## Layout of several tables

`tablesPerRow`, `tableColumnGap` and `tableRowGap` decide where each `.table()` lands. [Building Workbooks](/workbook/building-workbooks#several-tables-on-one-sheet) shows both layouts.

```ts twoslash
import { createWorkbook } from "typed-xlsx";

createWorkbook().sheet("Dashboard", { tablesPerRow: 3, tableColumnGap: 2, tableRowGap: 2 });
```

## Right-to-left

```ts twoslash
import { createWorkbook } from "typed-xlsx";

createWorkbook().sheet("تقرير", { rightToLeft: true });
```
